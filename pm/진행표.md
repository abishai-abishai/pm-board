# 예시 프로젝트 진행 현황

> ⚠️ **이 파일은 `node pm/make-report.js --write` 가 자동으로 씁니다. 손으로 고치지 마세요.**
> 고치면 다음 실행 때 덮어써집니다. 정본은 `pm/kanban.json` 입니다.

**일감 하나가 다섯 칸을 왼쪽에서 오른쪽으로 옮겨 갑니다.** 사람이 끌어 옮기지 않습니다.
앞 칸이 완료여야 다음 칸으로 갑니다. 보류는 그 자리에 섭니다. (규칙 정본은 `docs/기능정의서.md`)

```
기획  →  개발  →  QA  →  릴리즈 대기  →  배포 완료
PL       FE·BE   QA     RL(대기)        RL(완료)
```

상태 기호: ⬜ 대기 · ⏳ 진행 중 · 🔧 수정 완료(QA 전용, 검증 전) · ✅ 완료 · ⏸ 보류 · `·` 칸 없음
